### 🔥 Featured Projects

#### 🎬 [YouTube to LinkedIn Post Generator](https://github.com/ibrahimmlk) — *March 2026*
An AI-powered content repurposing app that takes a YouTube URL, extracts the transcript, and generates a polished, engagement-focused LinkedIn post.
- **Stack:** Python, LangChain, OpenAI SDK, youtube-transcript-api, yt-dlp, Streamlit
- Designed and tuned LangChain prompt chains for tone control, source attribution, and concise formatting
- Reduced manual content repurposing time from 30+ minutes to under 30 seconds

#### 📱 Socially (Social Media App) — *Sep - Nov 2025*
A full-featured social media Android application with photo sharing, real-time messaging, and in-app audio/video calling.
- **Stack:** Kotlin, XML, Firebase (Auth & Realtime DB), PHP REST API, Agora SDK
- Implemented Agora API for peer-to-peer calls and Firebase for real-time data sync
- Built an offline-first sync system using SQLite for posts/messages made without connectivity

#### 💳 Truvio Payment Passport — *April 2026*
A real-time payment verification and fraud protection network with a Node.js backend and a Manifest V3 Chrome Extension to intercept high-risk e-commerce transactions.
- **Stack:** Node.js, Express, MongoDB, Speakeasy (MFA), Plaid API, JWT, Manifest V3
- Engineered authentication middleware, transaction routing logic, and secure API endpoints
- Built a heuristic engine scoring transactions via device fingerprinting and velocity to trigger MFA/verification
